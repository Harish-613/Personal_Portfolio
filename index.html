Developer tool

Stratum

A VS Code extension that turns a codebase into an interactive dependency graph. A Python engine parses the repo with Tree-sitter, finds import cycles with Tarjan's algorithm, flags files nothing can reach, spots copy-pasted functions by hashing syntax trees, and re-analyzes as you save.

TypeScriptPythonTree-sitterGraphviz (WASM)VS Code API
